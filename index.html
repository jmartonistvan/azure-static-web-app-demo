Mit tud ez a demó

Az oldal célja, hogy legyen egy tiszta, gyorsan publikálható statikus kiindulópontod, amit bármikor össze tudsz kötni később Azure Functions vagy más backend megoldással.

Publikus URL

Kaphatsz hozzá egy publikus Azure URL-t, amit bárhonnan megnyitsz böngészőből.

https://your-app-name.azurestaticapps.net

Egyszerű deploy

GitHub repositoryból automatikus deployjal működik, így később minden commit publikálhat.

Framework: No Framework App location: / API location: (üres) Output location: (üres)

Későbbi bővítés

Később backenddel kiegészíthető APS login, callback és ACC projektlekérő végpontokkal.

/api/auth/login /api/auth/callback /api/acc/projects

Induló lépések

Ezt a három lépést érdemes megcsinálni, hogy perceken belül éljen a demó.

1

Másold be ezt a fájlt

Tedd `index.html` néven egy új GitHub repository gyökerébe.

2

Hozz létre Static Web Appot

Azure Portalban válaszd a Static Web App szolgáltatást és kösd össze a repóval.

3

Nyisd meg az URL-t

A létrehozás után kapsz egy publikus URL-t, amit már meg is tudsz osztani.

Készen áll a publikálásra

Ez a verzió még csak statikus, de tökéletes alap Azure-os bemutató oldalnak és későbbi APS / ACC integrációhoz.
